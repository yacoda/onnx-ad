# Slides: differentiating control flow

The visual companion to [`CONTROL-FLOW.md`](../../CONTROL-FLOW.md) — eight slides showing,
for each of `If`, `Scan` and `Loop`, the primal graph and what the forward and reverse passes
add to it.

```sh
make            # xelatex, twice
```

Needs XeLaTeX with beamer, TikZ, tcolorbox and the Lato and DejaVu Sans Mono fonts.
`slides.pdf` is committed so the deck can be read without a TeX installation.
